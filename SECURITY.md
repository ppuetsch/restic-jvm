# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/ppuetsch/restic-jvm/security/advisories/new),
not as a public issue. You get an answer within a week.

## Verifying releases

Releases are signed with the key in `signing-key.asc`
(fingerprint `7B34 1314 7ACE 1EDB 715F 6293 05A9 61D4 163E 33E5`) and carry a GitHub build provenance attestation;
see "Verifying a release" in the README.
